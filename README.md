# 💳 منظومة اشتراكات وتفعيل جيب كارت (Jeep Card Ecosystem)

نظام متكامل لإدارة اشتراكات وتراخيص تطبيق **جيب كارت (Jeep Card)**، يشمل خادم backend مركزي، موقع ويب للعملاء، لوحة تحكم وتطبيق للمالك، والتكامل مع تطبيق أندرويد العميل.

---

## 🏗️ مكونات المنظومة

1. **الخادم المركزي (Central Backend & API)**:
   - مسار المجلد: `JeepCardServer/`
   - التقنيات: Node.js, Express, SQLite/JSON Store, Crypto (HMAC-SHA256).
   - المنفذ الافتراضي: `3000` (`http://localhost:3000`).
   - تشغيل الخادم:
     ```bash
     cd JeepCardServer
     npm install
     node server.js
     ```

2. **موقع العملاء للربط وطلب الاشتراك (Customer Web Portal)**:
   - الرابط: `http://localhost:3000/`
   - تصميم عربي RTL حديث (Cairo, Glassmorphism, Responsive).
   - إدخال كود الربط المكون من 8 خانات (`K7P9-X4QM`).
   - عرض حالة الجهاز، العمليات المجانية المستخدمة والمتبقية من الـ 50.
   - اختيار باقات الاشتراك:
     - **شهر (30 يوماً)**: 2,500 ريال يمني
     - **6 أشهر (180 يوماً)**: 5,000 ريال يمني (الأكثر توفيراً)
     - **سنة (365 يوماً)**: 10,000 ريال يمني
     - **دائم (مدى الحياة)**: 50,000 ريال يمني
   - إرسال الطلب ومتابعة حالته مباشرة (Polling حي).

3. **لوحة تحكم وتطبيق المالك (Owner Admin Panel & Mobile App)**:
   - الرابط: `http://localhost:3000/admin/`
   - رمز الدخول السري (PIN): `123456`
   - المميزات:
     - نظرة عامة وإحصائيات مباشرة.
     - مراجعة طلبات الاشتراك المعلقة.
     - قبول الطلب مع إمكانية تعديل الباقة أو منح مدة مخصصة (مثلاً 45 أو 90 يوماً).
     - رفض الطلب مع تحديد السبب.
     - إدارة التراخيص الصادرة (تمديد +30/+90/+365 يوم، إيقاف مؤقت، إلغاء نهائي).
     - إدارة أسطول الأجهزة وتعديل عداد الـ 50 عملية.
   - تطبيق هاتف المالك: متاح كـ PWA قابل للتثبيت مباشرة على الهاتف، أو عبر مشروع `JeepCardAdminApp`.

4. **تطبيق أندرويد العميل (Jeep Card Client App)**:
   - كود فريد لكل جهاز مبني على بصمة العتاد (`DeviceIdentityManager`).
   - حماية عداد الـ 50 عملية المجانية من التصفير عند الحذف وإعادة التثبيت (`Anti-Reset`).
   - توليد كود ربط مؤقت (`Pairing Code`) للطلب من الموقع.
   - محرك تحقق رقمي مشفر (`LicenseVerifier` بتقنية HMAC-SHA256).
   - حماية ضد التلاعب بساعة وتاريخ الهاتف (`Anti-Rollback`).
   - شاشة "الاشتراك والتفعيل" مدمجة في القائمة الجانبية للتطبيق.
   - العمل دون إنترنت (`Offline Resilience`) بعد التفعيل.
   - ملف التثبيت المحدث: `app/build/outputs/apk/debug/Jeep card.apk`.

## 🧪 اختبارات النظام والتحقق

- لاختبار الخادم والمحرك المشفر:
  ```bash
  cd JeepCardServer
  node test.js
  ```
- لاختبار دورة الحياة الشاملة (E2E Simulation):
  ```bash
  cd JeepCardServer
  node e2e_simulation.js
  ```
- لاختبار تطبيق أندرويد:
  ```bash
  cd MikroTikAutoCardProject
  .\gradlew.bat testDebugUnitTest
  .\gradlew.bat assembleDebug
  ```
